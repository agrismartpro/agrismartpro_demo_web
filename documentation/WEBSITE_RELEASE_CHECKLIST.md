# Checklist di rilascio del sito pubblico

Versione: 1.0
Stato: non autorizzata alla pubblicazione

## Repository

- [ ] branch corretto;
- [ ] working tree pulito;
- [ ] tag di backup verificato;
- [ ] `CNAME` uguale a `www.agrismartpro.com`;
- [ ] nessun file dell'app operativa incluso accidentalmente;
- [ ] nessun segreto.

## Contenuti

- [ ] copy approvato;
- [ ] stato delle funzioni aggiornato;
- [ ] nessun prezzo non approvato;
- [ ] nessun Payment Link;
- [ ] nessun claim normativo improprio;
- [ ] nessuna funzione futura presentata come disponibile;
- [ ] contatti verificati;
- [ ] copyright 2026.

## Legale

- [ ] Privacy verificata;
- [ ] Termini verificati;
- [ ] Cookie verificata;
- [ ] titolare e contatti corretti;
- [ ] strumenti effettivamente utilizzati coerenti con le informative.

## Collegamenti

- [ ] link interni validi;
- [ ] Accesso collaudato prima dell'attivazione;
- [ ] Registrazione collaudata prima dell'attivazione;
- [ ] richiesta demo approvata;
- [ ] nessun parametro aziendale o commerciale proveniente dal browser;
- [ ] eventuali social realmente esistenti.

## Qualità

- [ ] build locale;
- [ ] test statici;
- [ ] anteprima desktop;
- [ ] anteprima mobile;
- [ ] tastiera;
- [ ] contrasto;
- [ ] movimento ridotto;
- [ ] immagini e testi alternativi;
- [ ] metadata SEO;
- [ ] Open Graph;
- [ ] favicon;
- [ ] prestazioni accettabili.

## Pubblicazione

- [ ] autorizzazione esplicita ricevuta;
- [ ] commit approvati;
- [ ] push autorizzato;
- [ ] anteprima remota verificata;
- [ ] piano di rollback;
- [ ] confronto checksum della versione pubblicata;

La pubblicazione, il push e qualsiasi modifica DNS restano fuori dal perimetro
di questo incremento.
